Special Multipliers

Fixed bonuses applied after rarity + trending scoring. Each trait slot: Any (has trait) = that inscription must have a non-empty value in that slot (any listed variant). None (empty) = that slot must be empty or missing. Specific values match exactly. Combos with eight “Any” rows only match dogs that have all eight trait slots filled. Positive multipliers boost; negative use (1+m). Click Save Special Multipliers to persist.
